# Text Similarity & Plagiarism Checker

This project demonstrates how to detect similarity between text documents using
TF-IDF vectorization and cosine similarity.

## 🚀 Features
- Converts text into numerical vectors using TF-IDF
- Calculates cosine similarity between documents
- Identifies potentially similar (plagiarized) content
- Simple and beginner-friendly Python implementation

## 🧠 Concepts Used
- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Cosine Similarity
- Python Functions & Data Structures

## 🛠 Tech Stack
- Python
- scikit-learn

pip install scikit-learn
